# Как участвовать

1. Сначала посмотри [порядок карточек](astro-yoga/01-aries/README.md) и соответствующий `source.html`.
2. Опиши одну конкретную правку в Issue: читаемость, доступность, неточность текста или техническое улучшение.
3. Для изменения кода предложи Pull Request с указанием номера карточки и скриншотом результата. Не заменяй авторские изображения без согласования.

Связь асан и зодиакальных образов — авторская идея. Предложения по упражнениям должны сохранять бережную формулировку и не обещать лечебный эффект.
