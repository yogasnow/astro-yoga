# Yoga · Astro-Yoga

Рабочее пространство Снежаны для учебных карточек йоги. **Сейчас репозиторий закрыт.** Здесь собрана первая подтверждённая последовательность «Овен» и отдельно помечен черновик первой карточки «Тельца». Связь знаков и асан — авторская метафора, не традиционный канон и не медицинская рекомендация.

## Начать

1. [Глава 01 · Овен: 12 карточек](astro-yoga/01-aries/README.md) — от «Воина I» до «Шавасаны».
2. В каждой папке `01`–`12`: `card.png` — карточка, `source.html` — исходный HTML/CSS-макет, `asset-*` — изображения, от которых он зависит. Ссылки внутри макетов переведены на относительные пути.
3. [Глава 02 · Телец](astro-yoga/02-taurus/README.md) — пока только первая карточка «Врикшасана», статус черновика.

**Статус:** перенесены доступные локальные материалы; полный перенос всех карточек из Telegram пока не подтверждён. Старый 12-страничный PDF Тельца не включён: позднее его визуальную схему попросили исправить. [Что сверено и чего не хватает](PROVENANCE.md).

**Дальше:** согласовать визуальный и текстовый вариант главы Тельца, найти остальные исходники/карточки в теме, проверить асаны на практике и только затем обсуждать открытие репозитория.
