# Астро-йога · карточки и код

Авторский цикл Снежаны: практика йоги, визуальные карточки и образы зодиака. Снежана использует собственную внешность как отправную точку визуальной работы. Связь знаков и асан здесь — творческий учебный приём.

## Смотреть и продолжать

1. [Овен · 12 карточек](astro-yoga/01-aries/README.md) — первая полная глава, от «Воина I» до «Шавасаны».
2. [Телец · начало главы](astro-yoga/02-taurus/README.md) — первая карточка «Врикшасана», пока черновик.
3. [Как устроен исходник](#открытый-код) — для тех, кто хочет изучить или улучшить визуальные макеты.

## Открытый код

В каждой папке главы Овна: `card.png` — готовая карточка, `source.html` — её HTML/CSS-макет, `asset-*` — необходимые изображения. Открой `source.html` в браузере, изучи структуру и предложи улучшение через GitHub Issue или Pull Request. Код и изображения доступны для просмотра; условия повторного использования или коммерческого выпуска нужно согласовать с автором отдельно.

**Статус:** глава Овна собрана; Телец продолжим после авторской проверки. Следующий шаг — дополнить главу Тельца и сверить остальные карточки Telegram-темы. [Карта переноса](PROVENANCE.md).
